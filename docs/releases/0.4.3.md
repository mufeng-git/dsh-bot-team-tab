# 0.4.3

工程工具版：不改界面与交互，补上三样让迭代不再返工的东西。

## 产物

| 文件 | 说明 |
| --- | --- |
| `scripts/asar.mjs` | 读 Electron `app.asar`：`paths` / `ls` / `cat` / `get` / `find`，零依赖 |
| `scripts/deploy.mjs` | 装进 profile 并校验「profile 版本 / `lib/client.js` sha256 / `VERSION` 常量」三点一致 |
| `docs/checklist.md` | 开工前逐条打勾的条文，每条附反例 |
| `test/version.test.mjs` | 守住 `package.json` 与 `VERSION` 常量一致 |

## 校验

- `npm run check` 三关全绿：`node --check lib/client.js`、`node:test`（6 个文件 / 19 用例 / 63 条断言）、`scripts/check-docs.mjs`。
- `npm run deploy` 输出三行 `ok`，并在结尾提示彻底重启 DSH。

## 已知限制

- `scripts/` 与 `test/` 不进 npm 包（`package.json` 的 `files` 只含 `lib`、`cordis.patch.yml`、`README.md`、`docs`），所以装机后的副本里没有这两个命令；它们是仓库里的开发工具。
- `asar.mjs` 只读不内嵌压缩包的 `unpacked` 条目：这类文件在 `app.asar.unpacked` 目录里，直接读目录即可。

## 回退

`dsh plugin --profile desktop add github:mufeng-git/dsh-bot-team-tab#v0.4.2` 即可退回上一版；界面行为完全一致。
