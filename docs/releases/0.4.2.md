## 本版验收范围

1. `npm run check` 三关全绿：`node --check lib/client.js`、`node:test` 18 用例 / 61 断言、`scripts/check-docs.mjs` 文档死链检查。
2. 与 0.4.1 的 16 项相比新增的覆盖：`main` 页对每个 Bot 都先于其行注册；Bot 移出名册时行与页一并注销、回归后重新注册；Bot 改名后行名实时跟随；`openSession` 抛错 / 无 `uiWorkspace` / 无会话三条分支各自记录对应日志事件。
3. 装机后日志出现 `v:"0.4.2"`，左栏玄机 / 安澜两行仍在，点击仍进入对应会话，行图标仍按 `avatar.shape` 绘制。

## 已知限制

- `node --test` 默认按文件派生进程；本仓库改用 `--test-isolation=none` 单进程运行，以免在受限宿主上因 `spawn` 被拒而失败。测试进程因客户端 5 秒轮询不会自然退出，故带 `--test-force-exit`。
- 文档死链检查只覆盖 Markdown 链接与反引号内的文件路径，不校验锚点。
- 未做：不引入 vitest / biome / monorepo——与「零依赖、`pnpm add github:` 即装即用」冲突。
