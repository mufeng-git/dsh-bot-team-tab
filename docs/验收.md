## 已知取舍

- 侧栏不支持原地展开二级列表，故每个 Bot 独占一行，不提供分组或折叠。
- 只读：不建 Bot、不改模型、不代发消息、不启停 Bot。
- Bot 无会话时该行仍显示（名册来自 DS Bot 的 `state`，行点击后宿主会提示无会话）。
- DS Bot 切到 bot 模式（`localStorage['ds-bot:surface'] = 'bot'`）后整列被其 TeamSidebar 接管，本插件的行与 DSH 原生全局行一同不可见；该模式由 DS Bot 侧决定，插件不介入。

## 排障入口

- 行不出现：看日志有无 `row:register`；没有则查 `poll:error` 与 `apply:error`。
- 点了没反应：看 `jump:*` 与 `services:ready` 的 `probe`。
- 版本不符：日志 `v` 字段即实际装载版本；客户端 bundle 在启动时装载。
