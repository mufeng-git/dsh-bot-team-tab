## 手动验收（待你在真机上看）

1. [ ] **左侧栏「新建」下方出现「团队」** —— 刷新页面后，左栏「新建」正下面一行「团队」，图标是线性 users，排在「插件」「定时」等入口之前（order -1，内置插件入口是 0）。
   验：截图或口头确认。看不到就查 profile package.json 的 bundles 那行 + 控制台 `[dsh-bot-team-tab]` 报错。
2. [ ] **点「团队」→ 中间列换成名单** —— 点击后中间面板显示「团队 N 个 Bot」，左栏该行高亮；再点「新建」或会话能切回去，原对话不丢。
3. [ ] **4 个 Bot 时 4 行，且与 DS Bot 一致** —— 名字、角色、分组与 DS Bot 侧栏一致，主 Bot 行带「主」徽标。
4. [ ] **发消息后 5s 内变绿并显示阶段，跑完 7s 内回落** —— 给某个 Bot 发一条会调工具的消息：≤5 秒该行转绿实心圆、文案出现「工具名 · 文件名 · 已跑时长」；turn 结束后 7 秒内转青空心圆再回灰。
5. [ ] **点行切会话，切过去能直接发消息** —— 点任意一行，主视图切到该 Bot 的会话且输入框可用。
6. [ ] **离开面板 10 分钟，宿主 CPU 无异常、无 401/404 刷屏** —— 面板切走后 `api/bot` 应停止；DevTools 里不该有成片 4xx。
7. [ ] **DS Bot 停掉时显示空态，不崩不转圈** —— 应显示「还没有 Bot · 去 DS Bot 建一个」或带「重试」的错误条；DS Bot 回来后自动恢复。
8. [ ] **普通会话列表里 Bot 那几行尾巴上有 BOT 胶囊** —— 玄机、安澜的会话行尾部能看到小胶囊；普通会话行没有；鼠标悬停胶囊显示「Bot · 名字」。刷新后 20 秒内出现，不闪。

## 已知取舍（不是缺陷）

- 侧栏内不内联展开 Bot 列表：官方 `sidebar.workspaces` 被 ui-workspace 独占，内联只能 DOM 注入，主题/结构一变就散。要内联版另行评估。
- 只读：不能建 Bot / 改模型 / 代发消息 / 停 Bot。
- private Bot 只显示名字与状态；群聊不在 v1 内。
