## 手动验收（待你在真机上看）

1. [ ] **「+」菜单出现「团队」** —— 装完重启 dsh web，侧栏「+」里能看到「团队 / Team」，图标是线性 users，位置在靠后（order 60）。
   验：截图或口头确认。

2. [ ] **4 个 Bot 时 4 行，且与 DS Bot 一致** —— 建/保持 4 个 Bot，本页应恰好 4 行，名字、角色、分组与 DS Bot 侧栏一致，主 Bot 行带「主」徽标。
   验：两边并排看，行数与分组对上。

3. [ ] **发消息后 5s 内变绿并显示阶段，跑完 7s 内回落** —— 给某个 Bot 发一条会调工具的消息，盯本页：≤5 秒该行转绿实心圆、状态文案出现「工具名 · 文件名 · 已跑时长」；turn 结束后 7 秒内转青色空心圆再回灰。
   验：秒表掐一下；若 5 秒没动静，看是否被退避（连续失败时最长 30 秒一次）。

4. [ ] **点行切会话，切过去能直接发消息** —— 点任意一行，主视图应切到该 Bot 的会话且输入框可用；能发出去、有回。
   验：点一个闲置 Bot，发「在吗」。

5. [ ] **关页面 10 分钟，宿主 CPU 无异常、无 401/404 刷屏** —— 本页开着但窗口最小化/切到别的标签 10 分钟，回来时行状态应是最新的；DevTools Network 里 `api/bot` 在页面隐藏期间应当停止，恢复后回到 3 秒一次；不该出现成片的 4xx。
   验：开 DevTools 放着，10 分钟后看 Network 与 Task Manager。

6. [ ] **DS Bot 停掉时显示空态，不崩不转圈** —— 停掉 DS Bot（或让它暂时不可达），本页应显示「还没有 Bot · 去 DS Bot 建一个」或带「重试」的错误条，不白屏、不永久转圈；DS Bot 回来后自动恢复。
   验：停服务，刷新本页。

## 已知取舍（不是缺陷）

- 本页是**会话级**的：切进某个 Bot 的会话后，那一侧没有这个 tab。这是 better-sidebar 的 tab 存储方式决定的，不是漏做。
- 只读：不能建 Bot / 改模型 / 代发消息 / 停 Bot。
- private Bot 只显示名字与状态；群聊不在 v1 内。
