## 3. 左栏图标（方案 B）

### 3.1 插槽契约（已核）

- 行本体由宿主画：`SidebarRoot.tsx:94-96` → `renderFactorySlot('sidebar.panel.icon', { id, size: wide ? 16 : 18, active })`。
- 工厂再回到行注册项取字形：`PanelIcon.tsx:13-14` → `renderSlot('sidebar.panellist', { size, active }, { only: id })`。
- 所以 `register({ name:'sidebar.panellist', id, order, label }, Icon)` 的第二参就是这个行的图标组件，收到 `{ size, active }`。
- 现状：`lib/client.js:284-294` 的 `BotIcon` 对所有 Bot 返回同一个机器人剪影（`lib/client.js:556` 注册时用它）。

### 3.2 字形表（16x16 viewBox，仅描边、1.25px、圆角端点，不填充）

| `avatar.shape` | 意象 | 画法要点 |
|---|---|---|
| `whale`（默认） | 鲸 | 身体弧 + 尾鳍缺口 + 一只眼点 |
| `star` | 星 | 五角星轮廓，内角不断笔 |
| `moon` | 月 | 双弧月牙，开口向右 |
| `wave` | 浪 | 两道波纹，上短下长 |
| `squircle` | 圆角方 | 单圆角矩形，内一道短横 |
| `zed`（DS Bot 里叫 Bull） | 牛 | 牛角弧 + 鼻垫 |
| `hex`（DS Bot 里叫 Blossom） | 花/六边 | 六边形，中心一个点 |

取值依据：`ds-bot/src/host/roster.js:104` 校验 `/^[a-z][\w-]{0,31}$/`；默认 `whale`（`src/host/store.js:184`、`roster.js:936`）；7 个键见 `ds-bot/client.js:13599-13605`（`whale star moon wave squircle zed hex`）。

**未知 shape** → 回退到现在的 `BotIcon` 机器人剪影（保证任何新 shape 都不会画成空白）。

### 3.3 风格约束

- 单色描边，颜色 `currentColor`，不引入 Bot 自己的颜色（左栏图标是导航符号，配色跟随宿主主题；彩色会破坏一致性，用户要求「保持一样风格」）。
- 16px（宽栏）/ 18px（窄栏）由宿主传入，组件只吃 `props.size`。
- `active` 选中态不额外上色，交给宿主行的选中样式。
- 行 label 仍是 Bot 名（`label()` 实时读 store，改名即时生效；沿用 0.3.4 实现）。

### 3.4 实时性

字形在组件渲染时从 store 取当前 `shape`（按 `bot.id` 查），不固化进注册的闭包：在 DS Bot 里改了头像形状，下一次轮询（5 秒）后左栏图标跟着变，无需重启。

## 4. 会话头身份胶囊

### 4.1 插槽选择（已核，按优先级试）

`conversation.session.header` 整块是 `single / scope: session` 的原生标题栏（`conversation/src/client/contract/slots.ts:241-248`），注册它等于**替换** DSH 自己的标题栏——不做。

用它下面的附加位（`slots.ts:250-283`）：

| 顺序 | 插槽 | kind / scope | 位置 |
|---|---|---|---|
| 首选 | `conversation.session.header.actions` | list / session | 标题右侧、utilities 之前，可多个、按 order 排 |
| 备选 1 | `conversation.session.header.utilities` | list / session | 右对齐功能区 |
| 备选 2 | `conversation.session.header.corner` | single / session | 标题栏最右角（只有一个位置） |

三者都是附加位，不覆盖原生内容；首选失败才降级，不并行注册三个。

### 4.2 内容与显示条件

```
[字形 14px] 玄机  BOT
```

- 仅当**当前会话的 sessionId** 命中 store 里某个 Bot 的 `sessionId`（即 `chatOf(bot)`）时渲染；其他会话一律返回 `null`。
- 数据：`sessionId` 由 `session` 作用域的注入直接给出（slots 文档：session 插槽的 inject 收到 sessionId）；Bot 名/形状/角色/状态通过 `inject` 返回的 `hooks` 观察 store（`hooks: { roster: store }` → 组件拿到 `useRoster(selector)`）。
- 名字最长 12em，超出省略号；`BOT` 胶囊沿用 0.3.4 的会话行小标（9px、0.5px 边框）。
- 非交互（不用 button）：它只是身份标识，没有可点动作；tooltip 显示 `role` 与当前状态文案（复用 0.3.4 的六态词典，无状态时只显示名字）。

### 4.3 与 DS Bot 自身标题栏的关系（风险，须实测）

`ds-bot` 也注册了 `conversation.session.header`，但它是**包裹**而不是丢弃：`installHeaderNavigation` 会把自己之外的条目包进 `headerNavigation(entries2, face)` 再注册（`ds-bot/client.js:35943-35965`），所以原生的标题栏（连同 `.actions` 子位）仍然会被渲染。

验收时若发现：
- 胶囊在 DS Bot 模式里与它自己的 pill 重复 → 本期先接受重复（信息一致，不冲突），把去重列为后续项；
- 胶囊完全不出现 → 按 §4.1 顺序降级到 utilities，再不行降到 corner，并在日志里记 `header:slot` 事件说明最终落在哪个插槽。

## 5. 数据

```js
POST api/bot  { endpoint: 'state', payload: {} }
-> { ok: true, value: { bots: [ { id, name, role, color, avatar: { shape, image }, sessionId, ... } ] } }
```

- `view()` 把整个 bot 对象摊平后加 `sessionId`（`ds-bot/src/host/channel.js:71-79`），所以 `color` 与 `avatar` 本来就在回包里，**不需要新端点**。
- `normalize()`（`lib/client.js:92-112`）增补：`color: String(bot.color ?? '')`、`shape: String((bot.avatar && bot.avatar.shape) ?? '')`；缺省空串，渲染时按 `whale` 处理。
- 颜色取值集合（`ds-bot/src/host/constants.js:5`）：`deepseek blue violet orange green magenta cyan red yellow brown gray black aurora`；本期只用来给胶囊里的小方块做 8% 底色，取不到就不上底色。
- **不切 `avatars: 'ref'`**：本期不显示真实头像，没有取图需求；切 ref 反而要加 `avatar` 端点调用与缓存，属于净增复杂度。

## 6. 验收标准

自动化（`node scripts/selftest.mjs`，在现有 13 项上增加）
1. `normalize` 读出 `color` 与 `avatar.shape`；缺失时为 `''`，不抛错。
2. `shapeIcon('star')` 与 `shapeIcon('whale')` 返回不同路径；`shapeIcon('nope')` 回退到机器人剪影。
3. 行注册时图标组件按 `bot.id` 取当前 shape（改 store 后重渲染得到新路径）。
4. 身份胶囊：`sessionId` 命中 Bot 时渲染、未命中返回 `null`；名字超长截断。
5. `node --check lib/client.js` 通过。

真机（用户目视）
1. 左栏「玄机」「安澜」图标不再是同一个剪影；形状与各自 `avatar.shape` 一致。
2. 在 DS Bot 里把某个 Bot 的头像换成别的形状，5 秒内左栏图标跟着变。
3. 点行进入 Bot 会话，标题栏出现「字形 + 名字 + BOT」；点进**非 Bot 会话**（普通会话）不出现。
4. DS Bot 模式下不出现两个互相冲突的标题；若有重复，记录现象与截图，按 §4.3 处理。
5. 窄栏（折叠）下图标 18px 居中、不裁切。

## 7. 已知边界

- 宿主行结构只有 icon + label（`SidebarRoot.tsx:76-117`），没有行尾动作位——所以设置入口只能做在别处（本期不做）。
- `sidebar.panellist` 的行 label 是函数、图标是组件；两者都从同一份 store 读，改名/改形状都跟着刷新。
- 图标只影响左栏与「更多」菜单里的同 id 图标（`sidebar.panel.icon` 复用），不影响会话行尾的 BOT 小标。
- 插件外壳仍为纯客户端（`inject: ['slots']` + `ctx.inject(['uiWorkspace','layout'])`）；宿主半边只提供日志路由，不参与本期改动。
